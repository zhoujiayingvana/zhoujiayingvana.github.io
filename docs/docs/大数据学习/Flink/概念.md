# 乱序和迟到
1. 乱序与迟到的区别
    1. 乱序：数据顺序乱了，时间小的比时间大的晚来。仅在数据之间对比
    2. 迟到：数据的时间戳 < 当前的watermark。数据时间和watermark对比。有可能迟到的数据来了，但窗口没有触发输出。也有可能迟到的数据来了，但窗口已经触发，默认触发=关闭（要处理的是这些迟到数据）
2. 乱序、迟到数据的处理
    1. watermark指定乱序等待时间：窗口触发输出的时间也会延迟对应秒数
    2. 如果使用窗口，可以设置窗口允许迟到（正常触发输出，但延迟关闭。正常触发后，每来一条迟到数据，就输出一次）
    3. 关窗后的迟到数据，放入测流输出（sql无法做到，只有api能做到）
