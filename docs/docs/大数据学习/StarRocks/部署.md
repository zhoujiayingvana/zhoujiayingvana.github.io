### 安装NTP服务器
## FE配置修改
根据是否有域名来决定是否添加IP：子网是掩码20位，IP/20

添加存算分离的配置：s3的认证方式：应该是<font style="color:rgb(28, 30, 33);"> Instance Profile</font>

```bash
# metadata
meta_dir = /opt/starrocks/metadata
# 网络配置
priority_networks = IP/20

# 存算分离配置
run_mode = shared_data
enable_load_volume_from_conf = true
cloud_native_storage_type = S3

aws_s3_path = uat-tauc-aps1-data-analysis/starrocks
aws_s3_region = ap-southeast-1
# 待确认是否需要vpc的id
aws_s3_endpoint = https://s3.ap-southeast-1.amazonaws.com
aws_s3_use_aws_sdk_default_behavior = true
```

## BE配置修改
添加存算分离的配置

```bash
# 给fe节点留内存
mem_limit = 70%

# 减少存算分离缓存占用空间，占用后无法清除
starlet_star_cache_disk_size_percent = 20
```

## CN配置修改
```bash
priority_networks = IP/20
```
